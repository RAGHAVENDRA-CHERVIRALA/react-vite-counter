# Building a Simple Counter App with React.js and Vite

This application displays a counter with an initial value of 0 and provides four interactive buttons for users to modify the count:

1. Increment: Increases the count by 1 with each click.
2. Decrement: Reduces the count by 1 with each click.
3. Add: Boosts the count by 10 when clicked.
4. Subtract: Decreases the count by 5 when clicked.
